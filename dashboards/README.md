# Power BI Dashboard

customer_churn_dashboard.pbix is an unchanged copy of the supplied EDAI.pbix file.

The report layout contains Overall Churn Overview, Churn Analysis, and High Risk Profile. The page titles and main data labels are English; several automatic count/sum labels remain Chinese in the native file.

The file has not been opened, refreshed, or visually verified in Power BI Desktop for this package. Its layout references telco_powerbi, telco_powerbi1, and feature_churn_rate_gap_ranking. The first EDA notebook exports outputs/data/telco_powerbi.csv and the ranking table. The dashboard uses two Telco table names; both may need to be mapped to the corresponding source in Power Query. Original connection metadata may still need manual adjustment.

The native PBIX is kept so the original dashboard work remains available. Reconnecting or translating remaining automatic labels should be completed in Power BI Desktop.
